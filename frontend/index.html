Engineering Calculation Reference

Simulation Assumptions

The following engineering assumptions are applied throughout the simulator.

  • Zero Export Controller : Enabled
  • Utility Grid : Available
  • Inverter Efficiency : 98 %
  • Temperature Coefficient : -0.4 % / °C
  • PV Reference Temperature (STC) : 25°C
  • Standard Irradiance (STC) : 1000 W/m²

Available PV

Description

Maximum PV power that can be generated under the current environmental conditions before any Zero Export control is applied.

Inputs

  • DC Capacity
  • Irradiance
  • Module Temperature

Formula

Temperature Factor = 1 - (0.004 × (Temperature - 25)) Available PV = DC Capacity × (Irradiance / 1000) × Temperature Factor × (Inverter Efficiency / 100)

Engineering Note

Represents the maximum solar power available before the Zero Export Controller limits the inverter output.

Actual PV Output

Description

Actual inverter output after applying the configured Offset.

Inputs

  • Available PV
  • Factory Load
  • Offset

Formula

Target PV = Factory Load − Offset Actual PV Output = min(Available PV, Target PV)

Engineering Note

If Available PV is lower than the target, the inverter produces all available power. Otherwise, the Zero Export Controller limits the inverter output.

Factory Load

Description

Total electrical power consumed by the facility.

Inputs

  • Factory Load (User Input)

Formula

Factory Load = User Input

Engineering Note

Represents the instantaneous power demand that must be supplied by the PV system and/or the utility grid.

Export

Description

Electrical power exported to the utility grid.

Inputs

  • Actual PV Output
  • Factory Load

Formula

Export = max( 0, Actual PV Output − Factory Load )

Engineering Note

Under normal Zero Export operation, Export should remain at 0 kW. A positive value indicates power is flowing into the utility grid.

Import

Description

Electrical power imported from the utility grid.

Inputs

  • Factory Load
  • Actual PV Output

Formula

Import = max( 0, Factory Load − Actual PV Output )

Engineering Note

When sufficient PV power is available, Import is normally equal to the configured Offset. Otherwise, additional power is imported from the utility grid.

Curtailment

Description

Solar power intentionally reduced by the Zero Export Controller to prevent power export.

Inputs

  • Available PV
  • Actual PV Output

Formula

Curtailment = Available PV − Actual PV Output

Engineering Note

Curtailment represents available solar energy that is intentionally not generated because producing it would exceed the Zero Export target.
